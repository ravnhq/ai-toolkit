# QA Happy Path — Section Definitions

## Sections

### std — Shared Standards
Impact: CRITICAL
Order: 1
Rules that apply to every happy path test run regardless of mode.

### ui — UI Testing Rules
Impact: HIGH
Order: 2
Rules for browser-based interaction, snapshot verification, and network monitoring.

### rpt — Reporting Rules
Impact: HIGH
Order: 3
Rules for bug reporting format and issue tracker integration.
