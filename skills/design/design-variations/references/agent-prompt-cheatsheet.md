# Agent Prompt Cheatsheet

Per-profile example prompts distilled from brand DESIGN.md `§9 Agent Prompt Guide` sections. Use these as copy-pasteable templates when asking Claude for single-profile variations.

## Stripe

- "Build a pricing card with Stripe's signature: sohne-var weight 300 headline, blue-tinted shadows, purple accent (#533afd), no border radius above 8px."
- "Create a hero section using Stripe's editorial trust language: generous whitespace, light weight (300) headlines, dark navy (#061b31) text, layered shadows."
- "Design a form input using Stripe's system: 8px radius, purple focus ring, label in #273951 at 14px, placeholder in #64748d."

## Apple

- "Design a product card using Apple's cinematic rhythm: black hero chapter background (#000000) with centered white text, pill-shaped CTA (18px+ radius), minimal chrome."
- "Build a navigation bar inspired by Apple's retail aesthetic: compact dark translucent bar, small links (14px), blue action button (#0071e3), icon-minimal."
- "Create a comparison matrix with Apple's specs-focused approach: fixed left column (feature names), right columns for products, checkmarks and values, no extra decoration."

## Notion

- "Design a card using Notion's warm neutrals and whisper borders: #ffffff background, 1px solid rgba(0,0,0,0.1) border, NotionInter 22px weight 700 heading, soft blue (#0075de) accent CTA."
- "Build a feature section with Notion's editorial warmth: 64px headline with negative tracking (-2.125px), warm white (#f6f5f4) background section, 12px-radius image cards."
- "Create a pill badge using Notion's system: #f2f9ff background, #097fe8 text, 12px weight 600, 9999px radius, 4px padding."

## Vercel / Geist

- "Design a button using Vercel's stark typography: Inter 14px weight 600 or 700, black text on white, minimal padding, 0–4px radius (sharp edges), no shadow."
- "Build a hero using Geist's compression aesthetic: Geist font at 48px weight 600, negative letter-spacing (-2.4px), stark black/white contrast, single accent color."
- "Create a card with Vercel's minimalist approach: white background, 1px border #EAEAEA, no shadow, 0–4px radius, generous internal padding (20–24px)."

## Figma

- "Build a nav using Figma's design-tool aesthetic: light background, purple accent for active state, icons + text, compact spacing (8px grid)."
- "Create a feature highlight card: purple accent bar on left edge (4px), left-aligned content, image at top, title 20px weight 600, description 14px."

## Linear.app

## Spotify

- "Build a modal with Spotify's music-streaming aesthetic: dark bg, green accent, generous rounded corners (16–20px on main surfaces), high contrast text."
- "Create a navigation using Spotify's brand system: dark sticky header, green accent on active link, minimal horizontal spacing, medium-size type (14px)."

## Airtable

- "Design a card using Airtable's content-first system: clean white background, minimal borders, left-aligned text, small images/thumbnails on right, generous padding (16–20px)."
- "Build a form using Airtable's database aesthetic: label on top of input (not inside), subtle borders, light backgrounds, compact vertical stacking (12–16px gaps)."
- "Create a hero using Airtable's approachable tone: 48px headline weight 400 (light), warm neutral background, centered layout, hand-drawn or playful illustration."

## Cal.com

## Luxury / Editorial (Aesop, Hermès, NYT)

- "Create a CTA button in luxury style: text-only (no background), letter-spacing 0.15em uppercase, subtle underline on hover, long transition (600ms)."

- "Create a dashboard metric using Monzo's coral palette: #D96949 accent, 16px body text, clear label → value structure, subtle shadow (monzo: 4px cards)."
